# Raspberry Pi for Mere Mortals

The **Raspberry Pi** is a complete Linux computer the size of
a deck of cards — from $15 to about $150 depending on the
model. This guide compares **every current model**, tells you
honestly **which Pi fits which job**, walks through **headless
setup** (no monitor needed), and gives you **first projects**
that actually teach something.

No CS degree required. Ideas first, then real commands.

## What this guide covers

- [**What a Pi is**](what-is-a-pi.md) — single-board computer
  vs microcontroller (Pi vs Pico — they're different beasts)
- [**The lineup**](the-lineup.md) — Pi 5, Pi 4, Pi 500, Zero 2
  W, Pico, and Compute Modules compared spec-for-spec
- [**Which Pi for what**](which-pi-for-what.md) — home server,
  AI tinkering, IoT sensors, desktop, learning Linux: matched
  to models
- [**Headless setup**](headless-setup.md) — flash, enable SSH,
  join Wi-Fi, first boot — no monitor, no keyboard
- [**Pi OS essentials**](pi-os-essentials.md) — `raspi-config`,
  updates, the 64-bit question
- [**Your first projects**](your-first-projects.md) — one
  project per model class, each teaching a real skill
- [**Troubleshooting**](troubleshooting.md) — symptom → fix,
  eight ways

## What it doesn't cover

Custom HAT design, industrial Compute Module carrier boards,
and real-time bare-metal programming on the Pico (the
[Arduino guide](https://paulsullivan33-dev.github.io/arduino-for-mere-mortals/)
covers the microcontroller mindset). This guide is about
*choosing and running* a Pi.

## How to use this guide

Specs were checked against Raspberry Pi's official
documentation and multiple 2026 buying guides in October
2026. **Prices are approximate and volatile** — a DRAM
shortage has pushed Pi prices up several times since late
2025, so treat every price as "check before buying."
**Check:** blocks show verified output. Anything labeled
illustrative says so.
